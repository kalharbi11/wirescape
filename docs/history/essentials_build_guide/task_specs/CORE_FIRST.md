# Local core/integration tasks — not READY ordinary modules

Do not invent these interfaces in an external return ZIP.

- **VCA LPG:** preserve essentials.vca Gain ID0 and raw gain-CV multiplication/default ordinary VCA mode. First design mode ID/default, damping/brightness/decay, bypass/reset and state smoothing. An external isolated LPG kernel may be requested later; the final VCA mode belongs in a reviewed compatible enhancement.
- **ADSR gate cable:** define buffer gate threshold/edge, event-vs-cable precedence and note ownership. Preserve current host note/event behavior and saved parameter IDs.
- **Pitch/Quantizer:** settle continuous pitch unit/reference, musical scale/root representation, rounding/tie/hysteresis and pitch-CV sink before publishing a task. Current VCO receives Hz parameters and host note events, not a cable pitch input. A quantization math kernel is externally feasible once this contract is fixed.
- **Basic/Chord/Strum sequencers:** transport/lookahead, clock/reset, ordered note outputs, ties/retriggers, source/channel/note IDs, voice allocation/release/panic, saved patterns and overflow are core work. Do not fake chords as a single float or claim polyphony by simultaneous note-ons into the current monophonic ADSR/VCO.
- **MIDI/OSC/UDP:** shared service ownership, lifecycle/stop/reconnect, one enqueue owner, timestamp conversion, bounded ingress/egress, rate policies, packet bounds and endpoint/device identity first. MIDI output is a scheduled sink; OSC timetags/network clocks are not audio timestamps automatically. OSC numeric→CONTROL requires explicit bounded adapters; strings/binary/structured values remain on a typed asynchronous message path. Raw UDP is distinct from OSC parsing.
- **Monitor/Print and MIDI Monitor:** shared bounded log service with pause/clear/filter/copy/timestamps and dropped-count. Define pause-display vs pause-acquisition semantics. Never log/format unlimited data in processing or hold audio locks for UI copies.
- **Scope/Spectrum:** shared prepared audio/control tap, bounded snapshots/ring, decimation/FFT worker, GUI publication limits. Missing ABI tap/UI facade cannot be invented inside an ordinary DSP DLL. FFT/window/decimator kernels can be commissioned separately after this contract.
- **Plaits/Braids:** official source exists, but a desktop wrapper is a port, not a firmware drop-in. Choose ONE engine; pin revision and stmlib dependencies, identify DSP-only files vs hardware drivers, initialize memory/randomness, adapt sample rate/quantum, retain attribution and per-file licenses, then test one voice before polyphony. Do not download random prebuilt binaries or vendor the entire hardware firmware. See SOURCES.md.

The ready Clock emits CONTROL pulses; host clock/transport/event outputs remain future integration. The ready Function Envelope is a deliberately original gated rise/fall/curve generator, not an electrical or software clone of full MATHS. A full arithmetic module is not assumed easier merely because products/manuals exist online.
