# ABI2 SDK author guide — experimental foundation

1. Copy native/sdk/template into a new module folder. Keep GPL-derived DSP GPL; original SDK/template code is MIT. Never edit module2.h to fit a processor.
2. Include wirescape_sdk.h. Define a plain C++17 class with static constexpr ws::Info info{id,name,version}, std::array inputs/outputs of ws::port(...), and params of ws::param(...). Empty arrays use std::array<ws2_port,0> or std::array<ws2_param,0>.
3. port(id,name,hint=WS2_ANY,poly=WS2_POLY,unpatched=0,stereo_pair=nullptr,kind=WS2_SIGNAL). Voice channels are not left/right; stereo uses two ports linked by stereo_pair. EVENT ports are distinct from signals; hints never block signal connections.
4. param(id,name,min,max,default,unit,flags,taper,legacy_index,curve,step). String IDs are stable; legacy_index preserves ABI1 meaning. Defaults flags MODULATABLE|AUTOMATABLE, taper LINEAR. Log requires positive minimum. STEPPED bypasses host base smoothing. Host sends plain-unit parameter signals after normalized 5ms smoothing, summed modulation, clamp and taper.
5. Implement prepare(const ws::Setup&), reset(), process(ws::Block&). Setup exposes sample_rate(),max_channels(),max_block(), config.seed and alloc(bytes,alignment,hint). Use host FAST/LARGE memory only during setup; fixed prepared state remains bounded. If extra setup storage is required, static memory_requirements(config) returns ws2_memory for extra FAST/LARGE bytes; wrapper reports its own instance automatically.
6. Block.frames(),channels(),sample_rate(),frame_position(). Inputs: b.in(i).channels(),constant(),connected(),ch(c)[sample]. Parameters: b.param(i) has the same view. Host resolves broadcast/SUM/FIRST first; sample0 stands for all frames when CONSTANT. Outputs: b.out(i).set_channels(n),ch(c)[i],mark_constant(). Fill every nonconstant sample; for CONSTANT fill sample0. Signal max16 channels in foundation. Never assume block256 or one frame size.
7. b.events() iterates all sorted events (including direct host events); b.events_in(port) iterates that input port. b.split(range(first,end),event(e)) processes subranges between events; offsets refer to this process call. b.emit(output_port,event) returns false on bounded capacity; don't spin/retry indefinitely. Do not retain message data after the call. Handle nullable b.transport().
8. Optional query_ports(const ws2_config&,ws2_ports&) supplies module-owned immutable port arrays based on prepare config; preserve IDs. Optional save_state(ws::Writer),load_state(ws::Reader) return ws2_result and use versioned value()/bytes(). Validate first before changing state. Unknown future state must return UNSUPPORTED; host preserves the opaque bytes. Optional latency_frames() reports true path latency. See rows test for a bounded implementation.
9. Use ws::Schmitt (>0.5 on,<0.25 off), ws::Trigger (>=1ms), ws::Random (instance/channel seed), ws::simd::f4 (SSE2/NEON/scalar) and scalar paths. SIMD values use load/store and +,-,*. Keep double only with documented precision need. fastmath::tan_small is opt-in and restricted to |x|<=.25rad; not a full filter-range tan substitute. No fast-math global flags.
10. End source with WS_REGISTER_MODULE(Class). Library target prefix ws2_, stable essentials.* ID for approved ports. Entry macro WS_MODULE2_ENTRY_NAME and version macro WS_MODULE2_VERSION_NAME allow static naming. Add metadata/README/DESIGN and tests. C/C++ABI callbacks/validation/exception barrier are generated by ws::Module<Class>, not handwritten.

No allocation, locks, I/O, logging or thrown exceptions in processing/reset/events. No Qt/OS/platform intrinsics outside the SDK. Use explicit sample counts and deterministic reset. Tests: independent math/reference signals, frame/channel/rate matrix, gate/event timings, missing inputs, reset/state, finite extremes, CONSTANT correctness, actual wrapper calls, no-allocation instrumentation and documented memory. Use CTest and truthful reports. A desktop pass is not Daisy/CLAP proof; adapters are later. Don't add TrackC devices, patch/UI migration or additional module ports in this slice.

Testing bootstrap: template/tests.cpp is a self-contained C-callback harness with a fixed aligned host arena, ws2_config, signal/output arrays and ws2_process. Compile it alone because it includes module.cpp. Set every public struct_size, config max16 channels and sufficient frames; use the descriptor create/prepare/process/reset/destroy callbacks. The host owns arena storage until after destroy. Copy this bootstrap and add independent math, rate/channel/block and invalid-input tests for your module. Root CMake wires the executable/CTest; this is not a replacement for engine graph integration.

Guide exercise clarifications: `auto channel = b.in(0).ch(c)` is a constant-aware value view, not a `const float*`; index it with channel[i]. Only output ch(c) returns a writable pointer. Use Writer.u32/f32 and Reader.u32/f32 for portable little-endian state; value<T> is raw native layout and unsuitable for shared files without an explicit encoding contract. In module.json numeric indices describe the runtime parameter slots; they are not default parameter values. SDK authoring still requires tests of the generated C callbacks, not just the DSP method.

For a time loop, fetch `signal.row(channel, scratch, frames)` once per channel. It aliases a varying signal and expands a constant or missing channel into the supplied scratch row. Reserve separate rows for simultaneously live inputs in `prepare`, sized to `max_block()`, and include their bytes in `memory_requirements`. A bool-returning `prepare` returns false on allocation failure; void-returning prepare remains supported. The template demonstrates two rows; the VCA uses three and multiplies `audio*cv*gain` with `f4` chunks plus a scalar tail, preserving operation order. Keep CONSTANT output length at one sample. Hosts supply finite inputs and parameters; the SDK validates output samples.
