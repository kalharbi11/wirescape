# Wirescape 1.0

**Status:** in development. 1.0 is released only when the owner test passes with no major problems (PLAN D20, 2026-11-12).
**Commit:** pinned after the owner test passes; the owner fills in the SHA.
Install: [../INSTALL.md](../INSTALL.md).

## What's in 1.0
- **App:** Electron + Studio patch editor and a separate native `wirescape-engine`.
  Windows x64 WASAPI and Raspberry Pi 5. Saves and loads patches, Undo, and a module
  preset menu (a bad preset shows an error toast).
- **Groove:** a two-track 32-step sequencer with Pads/Roll editors, per-track
  lengths, conditions and gates. **Chord steps** (2–5 notes, inversions, scale
  chords) and **per-track speed** 1× ½ ¼ ⅛ (#505, #509, #516, #528, #534).
- **Chord** module: incoming note → chord (#511).
- **Notes→CV:** a polyphonic note allocator for voices (#512).
- **CHAOS-lite:** a sound engine with sine/triangle/S&H/smooth-random LFO and
  8 presets, plus the scenes `chaos-01…03` and the new S&H FX / smooth-random pad
  patches (#522, #531, #533, #583).
- **MIDI:** a keyboard/controller input, patchable CCs, and **MIDI Learn / Forget**
  on knobs (#210, #500).
- **OSC In** over UDP on `127.0.0.1` (default port 9000). LAN only with
  `--confirm-lan` (#518, #562).
- **Stereo pairs** connect all-or-nothing (#549). Audio route/rate refusal (#399).
  Windows timing fix (#572).
- Oscillator pitch readout (#580), if it merged before the pinned commit.

### Also needed before 1.0 ships (owner, 2026-11-12)
- Owner-test fixes from #597: CHAOS Fall, reverb Mix, ASIO in the Windows build (#598, merged); Studio visuals: Random Source scope, unplug from either end, cable activity, Output meter (#599).
- **OSC finished:** friendly OSC In editor and the Monitor log (#603, #604, merged), per-route on/off (#612) and tolerant patch settings (#657).
- **Quad VCA / LPG** module and its Studio card (#601, #602).
- **ASIO drivers that fail to start are listed with a reason** (FlexASIO), with audio open errors in the status bar (#627).

## Known limits (for later updates)
- No installer: build from source.
- There is no OSC Out and no OSC in the browser demo.
- The Qt UI and ABI1 code are still in the repo but unused; removal continues in development after 1.0.
- 1.0 has no Pi evidence of its own yet; the last Pi-certified commit is `cd7999e`.
- The CHAOS performer strip was dropped.

## Owner test sheet (about 20 min)
Build with [INSTALL.md](../INSTALL.md) steps 1–4, then tick each line. You only
need to describe what fails.

| # | Do this | Pass if |
|---|---|---|
| 1 | `setup.ps1 -Ref …` | It ends with `windows-device-off-smoke-passed` |
| 2 | `Wirescape.cmd`, open `chaos-01-ember-veil-pad`, play the keyboard | Sound, and notes release cleanly |
| 3 | On the CHAOS card, change the LFO shape while holding a note; try 3 presets, then Undo | No click; Undo restores; a turned knob shows **Custom** |
| 4 | Groove → Notes→CV → VCO/ADSR/VCA → Output. Steps 16, Speed ¼, chords C F G C on pads 1/5/9/13, ties after each | One chord per bar, all voices sound |

| 6 | Keyboard → Chord → Notes→CV → voice | A chord on each key, no stuck notes on fast playing |
| 7 | MIDI Learn a knob from the Launchkey, then Forget | The knob follows the CC, then stops |
| 8 | Save, close the app, reopen, Load | Chords, speed, scale, knobs and mappings all come back |
| 9 | Play about 5 min at 48 kHz / 256 | No crackles (or paste the `overrun` lines) |

```powershell
py -3.12 -c "import socket,struct;socket.socket(2,2).sendto(b'/pico1/knob/1\0\0\0,f\0\0'+struct.pack('>f',0.8),('127.0.0.1',9000))"
```

## How to report
Post one comment on the 1.0 test issue:

```
Version: 1.0   Commit: <git rev-parse HEAD>   Machine: Windows <10/11>, <audio device>, <rate>/<buffer>
Pass: 1 2 3 …
Fail: <#> - what you did -> what happened (attach the terminal lines around it)
Other: anything that felt wrong or slow
```

Failures that block use are fixed before 1.0 ships (or in a 1.0.x update after it). Everything else waits for the owner to plan the next update.
