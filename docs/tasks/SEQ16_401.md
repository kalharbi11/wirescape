## Stable module contract

Keep `example.step_sequencer`; `clock`, `reset` inputs and
`pitch`, `gate`, `velocity`, `notes` outputs. Slots 0–25 and meanings
are immutable. Append `pitch9,gate9,vel9`
through `pitch16,gate16,vel16` at slots 26–49. Exactly 50 params.

Expand `length` to 1..16, but retain default 8 to preserve legacy patches
with implicit defaults. Bump descriptor version 1 -> 2. Playback-state
version 2 must accept valid version-1 state (steps 0..7) and reject corrupt
states atomically. Pattern data remains saved as 50 host parameters; no
new host/ABI/protocol, no opaque packed state.

Preserve the current same-frame reset+clock and external clock phase behavior
for version-1 patterns. No silent semantics migration. Gate, pitch, velocity
signal outputs and note events must retain exact existing behavior for
`length <= 8`; steps 9–16 follow the same path, including tie lookahead
and wrap.
