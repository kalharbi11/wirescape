# P1D: patch codec conformance + catalogue sync (Phase 1, parallel; best after P1A)

Make UI-saved patches load in the native engine, and native patches load in the UI, without losing anything (D3, D9).

**Read first:** the UI's `src/patch/types.ts`, `PatchDoc.ts`, `src/app/starters.ts`; native `native/document/runtime_patch.cpp` (what execution requires: `settings`, module `version`, `outputs[]` with `module`/`port`/`bus_channel`), `native/document/patch_document.cpp`, `docs/specs/patch_v2_draft.schema.json`, the UI repo's `docs/PHASE8_HANDOFF.md` table row 1.

**Build:**
1. **UI export:** fill a missing module `version` from the catalogue. Keep an existing `settings` as is, and add defaults only when absent. Keep `outputs[]` correct: adding an Output module adds its route, and deleting one removes only that module's routes. Never rename IDs or overwrite imported values. Unknown fields survive.
2. **Catalogue sync:** `tools/gen_ui_catalogue.py` builds `apps/studio/public/wirescape_modules.json` from the native manifests (`native/modules2/*/module.json`, `native/sdk/examples/*/module.json`). It keeps any UI-only presentation fields through a sidecar merge (`public/panels/*.json` stays as is). A `--check` mode fails CI on drift. Report, don't fix, any ID mismatch: IDs never change.
3. **Native conformance test:** CTest `ui_patch_conformance` loads every UI starter (exported via a small Node script in CI, or checked-in fixtures generated by the UI test) through `runtime_patch`. Starters that use modules not in the app catalogue (Step Sequencer, Random Source) must be refused with `unknown-module`, not crash. That's the expected v0 behaviour until 3C.
4. **UI round-trip test:** each `native/examples/*.json` loads in the UI and saves back with all unknown fields byte-equal by value.

```acceptance
tier: T2
size: <= 900 changed lines, <= 12 files
must_pass:
  - ctest --test-dir build/native -R ui_patch_conformance --output-on-failure --no-tests=error
  - python tools/gen_ui_catalogue.py --check
  - ci: web job green incl. round-trip spec
stops: [ID change, patch schema change, test removal]
```
