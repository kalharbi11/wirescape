**Recommendation for a bounded next research step:** prototype Clouds reverb as the first isolated candidate because it directly addresses the reverb requirement and its relevant source is MIT-licensed. Before any implementation/dependency decision, audit every file in its minimal dependency closure (including the pinned `stmlib` files), map its initialization/process calls to the module lifecycle, and measure CPU/memory on the Pi runner. Keep DaisySP as a lower-complexity delay/chorus reference; use `sst-effects` if broader algorithm choice outweighs dependency-surface cost. This recommendation is not a license approval or an RT/Pi-cost claim. Implement only under a separate authorized spike issue.

**Evidence limits:** commit and source/license headers were checked through GitHub's public API at the pins above. No candidate checkout, build, benchmark, or source integration was performed. A GPL-compatible repository banner alone is not sufficient for adopting any individual file; the future spike must record exact copied paths, pins, and licenses per `AGENTS.md`.
