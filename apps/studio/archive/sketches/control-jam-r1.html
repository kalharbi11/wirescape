Control jam

A sketchbook of options for how Wirescape's parameters look, behave and move. Nothing here is decided. Every idea has a code (T3, M5…) so you can react to it.

All modulation on this page is real in the sketch's own terms: the LFO card in section 06 drives "LFO 1" everywhere, the Clock drives the envelope and the port pulses, and the Chaos module drives "CHAOS X". Change the LFO rate and every knob listening to it changes pace.

No libraries are loaded. Every animation is plain CSS, the Web Animations API or one shared requestAnimationFrame loop, so the counter in the top right shows what the page really costs.

Knobs: drag up/down · shift for fine · double-click resets · click then wheel or arrow keys
Scrub numbers, tape, sliders: drag left/right
Displays marked "drag" can be grabbed directly
Top bar: Mod turns all modulation on and off · Motion slows or freezes time · Finish swaps the cap style of every knob that doesn't have its own · Pi 30Hz halves the frame rate, as the Pi profile would
Perf readout: main-thread time per frame for everything that's on screen, frames per second, and running Web Animations.
Feedback: tick keep / maybe / drop and type a note under any idea, then copy feedback and paste it back to me. It's saved in this browser as you go.
