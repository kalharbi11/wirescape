04 / Required state samples

Static truth table · no inferred audio/phase
Stopped / loaded

Native completed STOP confirmed and loaded generation known. Editor unlocked. Start only for the confirmed config.

Stopped / dirty

Authored draft differs from loaded config. Pattern can be edited and saved, but Start remains blocked until Apply ACK.

Running / locked

Both tracks show performance state. Grid and numerical inputs are read-only; no live pattern write command.

STOP queued / locked

Global STOP waits for the step-32 boundary. A command ACK is not completion. Second press cancels queue.

Applying

Prepared candidate submitted off render thread. Editor locked while awaiting loadGraph response; do not Start.

Refused / draft retained

Candidate not loaded; previous loaded graph cannot be confused with the edited draft. Start disabled.

Unknown / disconnected

Native completion/generation cannot be established. Status reads unknown; edits/Start disabled until confirmed.

Track mute / start queued

Track mute releases sound immediately but clock keeps running. Track Start while global run is active queues step-1 entry at shared boundary.

Off-page playhead

Selected page stays at steps 1–16 while native position may be step 23; label shows “step 23, off-page” without auto-navigation.
