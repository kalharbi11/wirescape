Groove sequencer: three ways to play it

Three working mockups for the two-track, 32-step Groove sequencer. Each one keeps the same Wirescape module card, the same transport and the same per-step data: Rest / Note / Tie, pitch, velocity, gate length, Mod 1 and Mod 2. Only the editing surface changes, so you can switch concepts and compare them on the same pattern.

Everything is simulated. The clock is a demo timer, not engine telemetry. Turn Sound on to hear a test tone, and switch Engine rules to compare the first release (edits are drafted, then applied at the loop end) with the later live-edit stage.
